# TireFlow ERP

Protótipo demonstrativo independente de um ERP white-label para borracharias e auto centers.

## Executar localmente

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000`.

Login demonstrativo: `admin@tireflow.demo` / `demo123`.

## Validação

```bash
npm run lint
npm run typecheck
npm run build
```

O projeto não possui banco conectado, autenticação real, variáveis de ambiente ou remote Git configurado.

Consulte `docs/tireflow-erp-arquitetura.md` para a arquitetura planejada.
